Task 1: Drawing Single-Color Triangles

To rasterize each triangle we test whether the center of the pixel lies inside it. It first checks that the framebuffer has nonzero dimensions and does not try to rasterize triangles with zero areas. Then we computed the triangles bounding box using the minimum and maximum x and y cordinates of its three vertices. Once we have those coordinates, we iterate through each pixel in the bounding box and test if it lies inside the triangle. Those points were turned into candidate pixel indices because the pixel (x, y) is samples at ( x + 1/2, y + 1/2), the horizontal candidate range starts at ceil(min_x - 1/2) and ends at floor(max_X -0.5). Then we calculate the vertical range in the same way and clip both ranges to the framebuffer boundaries. For each of those candidate pixels we evaluate three edge functions at its center. For a directed edge from A to B and sample point P, the helper edge function is: E(A, B, P) = (B.x - A.x) * (P.y - A.y) - (B.y - A.y) * (P.x - A.x). The sign indicates which side of the edges line containes the sample. The edges are calculated in order from V0 -> V1, V1 -> V2, and V2 -> V0. A sample is accpeted if all three edge vaules are nonnegative or all three are nonpositive. This is because both sign patterns allow the implementation to reasterize triangles with either clockwise or counterclockwise vertex orders. This also allows for samples that lie on the triangles boundary to be drawn. When a sample is then accepted, we call fill_pixel(x, y, color) using the integer pixel indices. Every accepted pixel recieves the same triangle color and this implementation uses one sample per pixel and includes all triangle edges instead of implementing the optional top-left edge rule. My implementation only tests pixel centers within the triangles bounding box, clipped to the framebuffer but it does not scan pixels elsewhere in the image. If the candidate region contains(B_w) columns and (B_h) rows the nested loop performs (B_wB_h) sample tests. Each test uses three edge function evaluations and a constant number of comparisons so the running time is (O(B_wB_h)). This meets the requirement that the algorithmn be no worse than checking every sample within the bounding box.
